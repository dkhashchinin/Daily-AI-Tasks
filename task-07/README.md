# Простой LLM агент с сохранением контекста

Агент принимает запрос пользователя, отправляет его в LLM через API и выводит ответ в веб-интерфейсе.
Запросы фронтенда выполняются через HTTP-клиент (`fetch`), бэкенд общается с LLM через OpenAI-совместимый эндпоинт.

## Сохранение контекста

История диалога хранится в SQLite (файл `conversation.db` в корне проекта):

- сохраняется вся история целиком — сообщения пользователя, ответы ассистента, вызовы инструментов (`tool_calls`) и их результаты;
- при перезапуске агента история загружается обратно из БД;
- диалог продолжается так, будто агент не выключался.

Управление историей: кнопка **«Сбросить»** в веб-интерфейсе очищает весь диалог.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и укажите свой ключ:

```
GPUSTACK_API_KEY=...
GPUSTACK_BASE_URL=https://gpustack.data.lmru.tech/v1
GPUSTACK_MODEL=deepseek-v4.1-flash
```

## Запуск

```bash
python -m app.web
```

Откройте <http://localhost:5000>
